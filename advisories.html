Missing authorization in WebSocket handlers

The Docker and terminal WebSocket handlers authenticated the session but never authorized it beyond an organization check. Any low-privilege member could open a root shell on the control-plane host or read the logs of any container.

CVE-2026-52824
2026-07-14

Default APP_SECRET in Docker image enables account takeover

The published Docker image shipped a fixed APP_SECRET. Any instance that kept the default allowed an unauthenticated attacker to forge signed tokens and take over an account, including administrators. Affects versions up to and including 2.57.0, fixed in 2.58.0.

Why the Dokploy links look different

Kimai ships as a Packagist package, so its advisories are promoted into the global GitHub Advisory Database and appear under github.com/advisories. Dokploy is not published to a supported package ecosystem, so its advisories stay scoped to the repository. They carry a real CVE ID assigned by GitHub as CNA, but they never enter the global database and do not surface in a credit: query. The links above point at the repository advisories, which are the primary record.
